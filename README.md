# 金工实习智能体

面向金工实习课程的 React 前端演示，默认展示数控车。学习工作台提供四个阶段：课前测评、理论学习及测评、实操考核、智能选学及课程反馈。下一步建议和阶段状态读取当前学生的本地学习记录。

## 本地运行

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

打开 http://127.0.0.1:4173/ 。构建命令为 `npm run build`，输出到 `dist/client`；构建结果需通过 HTTP 服务访问。

## 已实现的演示

- 课前素养测评与问卷记录得分、学习经历和希望加强的内容，直接决定进入理论阶段时打开的视频、章节或题库。安全题有误先看安全章节，需要从基础开始先看课程导入，其他学生按错题或问卷重点进入相应内容。
- 理论阶段可在视频、课程章节和题库练习之间切换。视频支持本地播放、按课时自动保存笔记和观看进度。刷新后重新选择原视频可续播。
- 学生界面的数字人伴学窗口可随时打开，按关键词查找示例课程资料并显示出处。程序章节保留 G00 / G01 的二维坐标示例。
- 示例题库支持随机出题、错题解析和重复练习。历史记录保留，达到总分与安全题要求后解锁实操。
- 实操材料信息、测量数据和过程说明提交。智能选学根据课前测评、问卷和最近错题推荐内容，学生可以保存学习心得或建议。
- 本地模式下，右上角用户菜单提供教师演示。云端模式下，教师登录后查看本班学生的课前学情与课程反馈。
- 记录按学生与工种区分，可以导出 JSON。数控铣、线切割、普通车与钳工显示待开放。

## 接入 Supabase 云端存档

Vite 仍按静态站部署。课前测评、调查问卷和课程反馈通过 Supabase Auth 和 Data API 读写。

1. 在 Supabase SQL Editor 中对目标项目执行 [问卷与反馈迁移](supabase/migrations/20261109000100_course_evidence.sql)。迁移创建三张表并启用行级访问控制。
2. 在 Authentication → Users 中由管理员创建并确认邮箱账号，设置初始密码。课堂试用可关闭自助注册。然后在 SQL Editor 给账号分配姓名、班级与角色。班级名使用包含学期和班号的唯一名称，教师与学生的班级名必须一致。将下列示例里的 UUID 和班级资料替换为实际值。

   ```sql
   insert into public.metalwork_profiles (user_id, display_name, student_number, class_name, role)
   values
     ('00000000-0000-0000-0000-000000000001', '测试学生', 'DEMO001', '2026秋 机械2401班', 'student'),
     ('00000000-0000-0000-0000-000000000002', '测试教师', null, '2026秋 机械2401班', 'teacher');
   ```

3. 在部署平台的**构建环境变量**里配置 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_PUBLISHABLE_KEY`。后者填 **Publishable key** 或旧版 **anon key**。禁止将 Secret key、service role key 或数据库密码填进 Vite 变量。使用 Node.js 22、`npm ci`、`npm run build`，发布 `dist/client`。
4. 用测试学生保存问卷和反馈，再在另一浏览器登录同一账号读回。用同班教师账号查看记录，并用其他班的账号验证访问隔离。先完成试验账号验证，再开始收集正式数据。

两个环境变量都未设置时运行浏览器本地演示。云端保存失败会保留表单供重试。旧版浏览器中的问卷和反馈不会自动绑定到云端账号，可以先用旧版的导出功能备份。

## 范围说明

课程、题目、理论达标规则与任务仍为教学示例，待教师审核。云端存档范围是课前测评、问卷和课程反馈。视频进度、笔记、伴学、题库练习和实操记录仍保存在当前浏览器。实操附件只记录文件名、类型与大小。

二维坐标视图并非真实机床仿真。平台资格不能替代现场教师确认；实际操作和最终实操评价由教师决定。清除浏览器数据会丢失本地记录。
