# 金工实习智能体

面向金工实习课程的 React 前端演示，默认展示数控车。学习工作台提供四个阶段：课前测评、理论学习及测评、实操考核、智能选学及课程反馈。下一步建议和阶段状态读取当前学生的本地学习记录。

## 本地运行

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

打开 http://127.0.0.1:4173/ 。构建命令为 `npm run build`，输出到 `dist/client`；构建结果需通过 HTTP 服务访问。

## 已实现的演示

- 课前素养测评与问卷，记录示例测评得分、学习经历和希望加强的内容。
- 理论阶段可在视频、课程章节和题库练习之间切换。视频支持本地播放、按课时自动保存笔记和观看进度。刷新后重新选择原视频可续播。
- 学生界面的数字人伴学窗口可随时打开，按关键词查找示例课程资料并显示出处。程序章节保留 G00 / G01 的二维坐标示例。
- 示例题库支持随机出题、错题解析和重复练习。历史记录保留，达到总分与安全题要求后解锁实操。
- 实操材料信息、测量数据和过程说明提交。智能选学根据课前测评、问卷和最近错题推荐内容，学生可以保存学习心得或建议。
- 教师演示入口位于右上角用户菜单，可以查看当前学生的课前学情与课程反馈，配置示例规则和记录实操评价。
- 数据按学生编号、工种区分，保存在当前浏览器，可导出 JSON。数控铣、线切割、普通车与钳工显示待开放。

## 范围说明

本项目不是已上线的正式教学系统。课程、题目、专业班级、规则与任务均为示例，待教师审核。尚未接入学校账号、真实权限管理、后台数据库、正式知识库或大模型。实操附件仅保存文件名、类型与大小，不上传或保存原文件。

二维坐标视图并非真实机床仿真。平台资格不能替代现场教师确认；实际操作和最终实操评价由教师决定。清除浏览器数据会丢失本地记录。
