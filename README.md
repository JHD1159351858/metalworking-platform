# 金工实习智能体

面向金工实习课程的 React 前端演示，默认展示数控车。首页采用浅灰白与蓝色的学习工作台，包含课程概览、完整设备示意、实训准备提示，以及视频学习、辅导学习、理论考核、实操考核四个核心入口。下一步建议与模块状态读取当前学生的本地学习记录。

## 本地运行

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

打开 http://127.0.0.1:4173/ 。构建命令为 `npm run build`，输出到 `dist/client`；构建结果需通过 HTTP 服务访问。

## 已实现的演示

- 首页、工种切换、学习身份选择、四模块二级页、知识库、学习中心和学习记录。
- 本地视频播放、观看时间与继续位置记录；课程视频尚未提供，刷新后需重新选择原文件。
- 基于示例资料的关键词辅导，明确显示资料名称与章节；巩固练习及记录。
- G00 / G01 与绝对 X、Z 数值的二维坐标连线。未知指令阻止解析，不模拟毛坯、刀具、切削成形或碰撞。
- 五道示例题随机排序、自动评分、总分与安全题双条件、补学入口、重考历史保留、实操资格解锁。
- 实操材料信息、测量数据和过程说明提交；教师演示入口位于右上角用户菜单，可配置示例合格线、任务说明并记录评价。
- 数据按学生编号、工种区分，保存在当前浏览器，可导出 JSON。数控铣、线切割、普通车与钳工显示待开放。

## 范围说明

本项目不是已上线的正式教学系统。课程、题目、专业班级、规则与任务均为示例，待教师审核。尚未接入学校账号、真实权限管理、后台数据库、正式知识库或大模型。实操附件仅保存文件名、类型与大小，不上传或保存原文件。

二维坐标视图并非真实机床仿真。平台资格不能替代现场教师确认；实际操作和最终实操评价由教师决定。清除浏览器数据会丢失本地记录。
