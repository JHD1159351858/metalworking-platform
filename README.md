# 金工实习智能体

面向金工实习课程的 React 前端演示，默认展示数控车。学习工作台提供四个阶段：课前测评、理论学习及测评、实操考核、智能选学及课程反馈。下一步建议和阶段状态读取当前学生的本地学习记录。

## 本地运行

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

打开 http://127.0.0.1:4173/ 。构建命令为 `npm run build`，输出到 `dist/client`；构建结果需通过 HTTP 服务访问。

## 已实现的演示

- 课前素养测评与问卷在首次进入课程时弹窗填写，可点击弹窗外空白处或关闭按钮收起。未提交草稿按学生与工种自动保存在当前浏览器，刷新后可从第一步继续填写。正式保存成功后不再自动弹出，第一步可查看只读结果。记录直接决定理论学习的起点。
- 理论阶段可在视频、课程章节和题库练习之间切换。视频支持本地播放、按课时自动保存笔记和观看进度。刷新后重新选择原视频可续播。
- 数控车课程章节对应超星《金工实习》第 8 章的 6 节。保留章节名称与资源数量，配有项目整理的学习要点和按节巩固题。综合练习保留安全知识达标条件。
- 超星的安全情景、工艺设计、质量检验和课后反思融入四个现有环节。第 8 章六节都有阶梯轴案例和独立练习。8.1 区分零点及方向错因，8.3 的工艺草稿可带入实操。导出资料中的数控车模块没有原任务点，数控车练习为项目编写的教学示例。
- 伴学在当前章节或视频旁提供基于课程资料的多轮引导，可以引用随堂笔记提问、把总结写回原视频。综合测评交卷前暂停答疑与历史查看。当前使用课程规则和资料检索。
- 示例题库支持随机出题、错题解析和重复练习。历史记录保留，达到总分与安全题要求后解锁实操。
- 实操页可提前拟工艺方案、练习公差判断。综合测评达标后可提交图纸版本、测量、过程和附件，教师可评分或退回某项。选学根据实际错因、提示使用、独立复测和补交要求推荐具体章节或字段，也可自主换方向、按章节提交反馈。
- 首次打开时显示访客首页，点击功能按钮弹出登录窗口。窗口提供超星登录和教师端登录。
- 选择「教师端登录」后输入教师密码。本地演示的默认密码为 `123456`，用于查看本浏览器内学生的汇总和明细。独立 Supabase 模式还须验证教师账号，查看本班学生的课前学情与课程反馈。
- 记录按学生与工种区分，可以导出 JSON。数控铣、线切割、普通车与钳工显示待开放。

## 接入独立 Supabase 云端存档

Vite 仍按静态站部署。课前测评、调查问卷和课程反馈通过 Supabase Auth 和 Data API 读写。

1. 在 Supabase SQL Editor 中对目标项目执行 [问卷与反馈迁移](supabase/migrations/20261109000100_course_evidence.sql)。迁移创建三张表并启用行级访问控制。
   随后执行 [课前测评仅提交一次](supabase/migrations/20261117000200_pre_assessment_once.sql)，保留已有测评数据并取消学生修改权限。云端以数据库记录作为完成依据，跨浏览器登录后也不会再次自动弹出。保存失败时保留弹窗和填写内容，可以重试。
   最后执行 [教师密码与会话权限迁移](supabase/migrations/20261118000100_teacher_access.sql)。教师密码初值为 `123456`，由数据库校验。正式收集学生数据前，请在数据库中更新 `metalwork_private.teacher_password` 的密码哈希，并清空 `metalwork_private.teacher_access` 以撤销已解锁的会话。
2. 在 Authentication → Users 中由管理员创建并确认邮箱账号，设置初始密码。课堂试用可关闭自助注册。然后在 SQL Editor 给账号分配姓名、班级与角色。班级名使用包含学期和班号的唯一名称，教师与学生的班级名必须一致。将下列示例里的 UUID 和班级资料替换为实际值。

   ```sql
   insert into public.metalwork_profiles (user_id, display_name, student_number, class_name, role)
   values
     ('00000000-0000-0000-0000-000000000001', '测试学生', 'DEMO001', '2026秋 机械2401班', 'student'),
     ('00000000-0000-0000-0000-000000000002', '测试教师', null, '2026秋 机械2401班', 'teacher');
   ```

3. 在部署平台的**构建环境变量**里配置 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_PUBLISHABLE_KEY`。后者填 **Publishable key** 或旧版 **anon key**。禁止将 Secret key、service role key 或数据库密码填进 Vite 变量。使用 Node.js 22、`npm ci`、`npm run build`，发布 `dist/client`。
4. 用测试学生保存问卷和反馈，再在另一浏览器登录同一账号读回。用同班教师账号验证密码后查看数据看板与学生明细，再用其他班的教师账号验证班级隔离。先完成试验账号验证，再开始收集正式数据。

云端保存失败会保留表单供重试。旧版浏览器中的问卷和反馈不会自动绑定到云端账号，可以先用旧版的导出功能备份。

平台托管环境通过 `CODER_SUPABASE_URL`、`CODER_SUPABASE_ANON_KEY`、`CODER_SUPABASE_TENANT_ID` 注入连接，学生可使用平台登录和首次自动建档。使用该模式时，教师工作台需要切换到配置了上述迁移的独立 Supabase 项目。显式配置独立 Supabase 时优先使用该项目。两种云端模式都未配置时运行浏览器本地演示。

## 超星账号登录

本地开发模式通过本机服务向认证中心验票。独立 Supabase 云端模式由 Edge Function 验票，平台托管模式沿用平台的超星 OAuth 代理。配置步骤见 [超星登录接入](docs/超星登录接入.md)。

## 范围说明

课程、题目、理论达标规则与任务仍为教学示例，待教师审核。云端存档范围是课前测评、问卷和课程反馈。视频进度、笔记、伴学、题库练习和实操记录保存在当前浏览器。新提交的附件原件保存在本机浏览器，既有提交若只有附件信息仍按原记录显示。导出的 JSON 包含附件信息。

二维坐标视图并非真实机床仿真。平台资格不能替代现场教师确认；实际操作和最终实操评价由教师决定。清除浏览器数据会丢失本地记录。
